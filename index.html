Mọi thứ bạn cần, không thứ nào bạn không

Được xây dựng cho người dùng thật — nhanh, gọn, bảo mật và mở rộng được.

Streaming Realtime

Phản hồi hiển thị từng token ngay khi model sinh ra, kèm chỉnh sửa message mượt mà. Không còn cảnh chờ đợi màn hình trắng.

Đa Model Linh Hoạt

Chuyển đổi giữa llama3.2, qwen2.5, mistral, gemma2, phi4 hay bất kỳ model nào trên Ollama chỉ với một dòng lệnh /model.

Vision & Phân tích ảnh

Gửi ảnh trực tiếp trong chat, bot tự động nhận diện và phân tích bằng các model đa phương thức như LLaVA, Qwen2-VL hay Gemma3.

Voice & Speech-to-Text

Nhắn tin thoại được chuyển thành văn bản tự động qua Whisper local, rồi trả lời bằng giọng nói với Piper TTS. Rảnh tay hoàn toàn.

RAG & Knowledge Base

Nhúng tài liệu PDF, Markdown, code vào vector store local (ChromaDB). Bot trả lời dựa trên chính dữ liệu của bạn, kèm trích dẫn nguồn.

Bảo mật & Riêng tư

Whitelist user/group, rate limiting, mã hoá token. Toàn bộ hội thoại nằm trong SQLite của bạn — không một byte nào rời khỏi máy.

Cách hoạt động

Ba bước. Không hơn.

01

Pull model về máy

Chạy ollama pull llama3.2 để tải model. Mọi thứ lưu local, không cần GPU đắt tiền — CPU cũng chạy tốt.

02

Khởi động bot

Điền TELEGRAM_TOKEN và OLLAMA_HOST vào file .env, rồi chạy ./install.sh (Linux/macOS) hoặc .\install.ps1 (Windows).

03

Chat & tận hưởng

Mở Telegram, gõ /start. Bot streaming phản hồi ngay lập tức — không latency cloud, không phí token.

Cài đặt

Deploy trong 60 giây

Chọn cách phù hợp với bạn. Tất cả đều dùng chung một file cấu hình .env.

Linux / macOS

Khuyến nghị · install.sh
# Clone repo git clone https://github.com/cuongng09/my_bot_restructured.git cd my_bot_restructured # Cài đặt chmod +x chatAi_bots/install.sh cd chatAi_bots ./install.sh

Windows

PowerShell · install.ps1
# Clone repo git clone https://github.com/cuongng09/my_bot_restructured.git cd my_bot_restructured # Cài đặt Set-ExecutionPolicy Unrestricted -Scope Process cd chatAi_bots .\install.ps1

Cấu hình .env

Bắt buộc
TELEGRAM_TOKEN=123456:ABC-DEF... OLLAMA_HOST=http://localhost:11434 DEFAULT_MODEL=llama3.2 ALLOWED_USERS=123456789 STREAM_MODE=true VISION_ENABLED=true
FAQ

Câu hỏi thường gặp

Đây là một bot Telegram mã nguồn mở, hoạt động như cầu nối giữa Telegram và Ollama — runtime LLM chạy hoàn toàn trên máy của bạn. Bạn có thể chat, gửi ảnh, gửi voice và nhận phản hồi từ các model AI mạnh mẽ mà không cần bất kỳ API trả phí nào.

Tối thiểu 8GB RAM để chạy model 3B–7B (llama3.2, qwen2.5:7b). Với model 13B–14B nên có 16GB RAM. Nếu có GPU NVIDIA từ 8GB VRAM trở lên, tốc độ sẽ nhanh hơn đáng kể. Bot cũng chạy tốt trên VPS CPU-only với model lượng tử hoá Q4.

Có. Bot hoạt động trong cả private chat và group. Trong group, bạn có thể cấu hình bot chỉ trả lời khi được mention (MENTION_ONLY=true), giới hạn người dùng bằng ALLOWED_USERS, và đặt rate limit để tránh spam.

Không. Toàn bộ quá trình suy luận diễn ra trên máy bạn thông qua Ollama. Lịch sử hội thoại lưu trong SQLite local. Bot chỉ giao tiếp với Telegram API để nhận/gửi tin nhắn — nội dung không đi qua bất kỳ server AI trung gian nào.

Có, từ v6.0. Vision sử dụng các model đa phương thức như llava, qwen2-vl, gemma3. Voice dùng whisper cho speech-to-text và piper cho text-to-speech — tất cả đều chạy local, bật/tắt qua biến môi trường.
